# Matchweek — Fútbol Internacional

Web responsive de demostración para consultar una agenda semanal (lunes a domingo), buscar equipos, filtrar por competición y abrir fichas con antecedentes ilustrativos.

## Uso

Abre `index.html` directamente en el navegador. No necesita instalar paquetes.

## Estado

**Este es un prototipo visual con datos de ejemplo, no un sitio con resultados en vivo.** Por ahora no hay API de fútbol ni automatización semanal. Los datos y horarios no deben publicarse como información deportiva verificada.

## Próxima fase

Conectar fuentes deportivas autorizadas, actualizar los encuentros semanalmente, verificar los resultados y generar análisis mediante IA. Se hará únicamente cuando se acuerde esa fase.
